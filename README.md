# Where Home Happens / 家在哪里发生

一个可以在 VS Code 中编辑的本地互动网站。主题为“家的定义”：从进入、聚集、饮食三个行为研究六个具有具体文化与历史语境的空间案例。

## 1. 启动

1. 解压整个文件夹，不要只取出 `index.html`。
2. 在 VS Code 中选择 **File → Open Folder**，打开 `home-atlas` 文件夹。
3. 安装 VS Code 的 **Live Server** 扩展。
4. 右键 `index.html` → **Open with Live Server**。

不需要 `npm install`，没有构建步骤。也可以直接双击 `index.html`，核心功能同样可用。页面、字体和示意图全部本地加载；只有点击外部研究来源时需要联网。

如果电脑安装了 Python，也可以在项目目录运行：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。Mac 上可能需要把 `python` 改为 `python3`。

## 2. 文件结构

```text
home-atlas/
  index.html           页面结构、导航和三个 dialog 阅读层
  styles.css           视觉变量、桌面布局、手机布局、打印样式
  script.js            中英文内容、来源、状态与完整交互
  assets/
    genkan.svg         玄关示意图
    porch.svg          门廊示意图
    majlis.svg         聚集空间示意图
    front-room.svg     前厅示意图
    frankfurt.svg      厨房示意图
    levine.svg         多用途公寓示意图
    favicon.svg        网站图标
  README.md            本说明
```

HTML、CSS、JavaScript 均包含中文分区注释与关键逻辑说明。SVG 也保留了用途注释。

## 3. 已完成的功能

- 空间图谱：桌面拖动画布，滑块缩放，RESET 恢复完整画面。
- 案例目录：切换为规整的索引，方便系统阅读。
- 三章节筛选：全部、进入、聚集、饮食。
- 六个完整案例：正文、研究解读、语境边界及可点击来源。
- 详情翻页：按钮与键盘左右箭头，遵循当前筛选结果。
- 双案例比较：选择任意两个案例，比较语境、进入方式、活动、物件与解读。
- Editorial：研究方法、图像说明、来源清单与设计鸣谢。
- 中英切换：右上角切换；语言偏好尝试保存在当前浏览器。
- 手机适配：小屏自动变为正常滚动列表，保留筛选、阅读与比较。
- 原生模态阅读层：支持 Escape 关闭、键盘导航、焦点限制和读屏标签。
- 打印摘要：Editorial 中点击“打印研究摘要”，可用系统打印保存 PDF。
- 减少动画：尊重设备的 `prefers-reduced-motion` 设置。

页面不上传访问者数据、不连接账户、不使用追踪脚本。localStorage 只保存语言；比较选择仅保存在当前页面内存，刷新后重置。

## 4. 怎样更改设计

### 配色

在 `styles.css` 顶部修改：

```css
:root {
  --olive: #747861; /* 主画布 */
  --pink: #ffdac9;  /* 标题与示意图的暖粉色 */
  --paper: #f1eee4; /* 阅读层纸色 */
  --ink: #020402;   /* 深色正文 */
}
```

SVG 中的颜色是独立值。若要一并修改平面图，用 VS Code 的“在文件夹中替换”，仅在 `assets/` 下替换相应十六进制颜色。修改后检查正文与背景的对比度。

### 字体与字号

全局字体位于 `:root`；大标题位于 `h1`；详情标题位于 `.reader-text h2`。目前只用系统字体，保证本地独立运行。如果加入字体文件，可把 `.woff2` 放进 `assets/`，再通过 `@font-face` 声明。

### 内容

打开 `script.js`：

- `I18N`：按钮、导航、界面标签。
- `SOURCES`：原始来源的标题和网址。
- `CASES`：六个案例的完整内容。

双语文本格式为 `[英文, 中文]`。案例的 `evidence` 是资料记录，`meaning` 是本项目的分析，`limit` 是研究边界。不要混写成未经来源支持的文化结论。

### 案例在画布中的位置

在 `CASES` 中修改：

```js
x: 85,       // 左侧位置，逻辑像素
y: 435,      // 上侧位置，逻辑像素
w: 260,      // 案例宽度
rotation: -4 // 旋转角度
```

画布逻辑尺寸为 1520 × 930，`fitCanvas()` 会按当前窗口适配。手机列表不使用这些坐标。

### 替换示意图或添加照片

将新图片放在 `assets/`，修改案例的 `image` 路径即可。建议保留至少 360 × 240 的清晰比例。`.case-image` 使用 `object-fit: contain`，不会裁切研究图。

替换成历史照片后，务必更新详情中的图像说明与 credits。现有六张图全部是原创解释性示意图，不是实测图，不是原始历史平面图，不能作为建筑实证。它们没有可用于测量的比例和尺寸。

### 新增案例

复制 `CASES` 的一个完整对象，给它唯一的 `id` 和编号，并填写所有字段，再添加本地图片。当前“06”总数标记为六案例版本设计，扩展数量时请同步修改 `index.html` 的总数、`applyFilter()` 的分母和首页说明。画布尺寸与坐标也需要重新安排。

## 5. 研究与视觉参考

六个案例使用此前讨论并核查的资料：The Japan Forum、Web Japan、Smithsonian、UNESCO、Michael McMillan / UAL、MoMA、Tenement Museum。页面内已保留具体链接。Daniel Miller 的 UCL 文稿列在来源中作为理论阅读。

这些是选择性的历史与文化案例，不是全球家庭的代表性调查。McMillan 的期刊论文仅使用公开摘要；已发表访谈是另一条独立来源。UNESCO 纪录片使用的是档案说明，没有虚构观看笔记或逐字稿。博物馆重构与历史原物已区分。

上传的印刷图像用于提炼橄榄绿、浅粉、折痕、旋转边注与大字排版。未将其中的品牌、地址或文字移植进本项目。

参考网页：<https://www.kellerstoecklarchitektur.at/>。借鉴空间索引、详情与 Editorial 分层阅读的逻辑；本项目代码与示意图独立编写，没有包含其摄影、字体文件或源代码。

## 6. 常见问题

**图片不显示**：确认 `assets` 和三个代码文件在同一级目录；路径区分大小写；不要从压缩包里直接打开 HTML。

**中文按钮仍然显示英文**：点击右上角“中文”；若需要默认中文，把 `state.lang` 的初始默认值从 `en` 改为 `zh`。浏览器保存的语言选择会优先采用。

**桌面画布看不到部分案例**：点击 RESET，或点击 WHH 返回全部案例。浏览器缩放建议设为 100%。

**第三个案例无法加入比较**：比较最多支持两项，先移除一项再添加。

**打印布局与网页不同**：打印使用独立研究摘要，每例一节，避免画布被截断；这是预期行为。

**以后要发布到 GitHub Pages**：把这个文件夹内的文件放到仓库发布根目录，保持 `index.html` 为入口。本交付未发布网站。

## 7. 手动检查清单

在你修改内容后，建议重新检查：桌面六案例是否可见；每个筛选是否显示两例；目录与空间图谱是否可切换；案例是否可关闭、翻页和访问来源；比较能否添加、移除与清空；中文切换后是否溢出；手机宽度 390px 时是否横向滚动；键盘 Tab / Escape 是否可用。
