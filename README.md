# Where Home Happens / 家在哪里发生

原生 HTML、CSS 和 JavaScript 网站，无需安装依赖或构建。

## 打开网站

在 VS Code 中打开整个项目文件夹，安装 Live Server 扩展，然后右键 `index.html` → Open with Live Server。也可以在项目目录运行 `python3 -m http.server 8000` 后在本地浏览器访问服务。

请保留 index.html、styles.css、script.js 和 assets 文件夹的相对位置。

## 当前交互

- 首次进入标签页时，WHERE HOME HAPPENS 逐字出现后淡入主页。可跳过；sessionStorage 记录当前标签页是否已播放。
- 界面采用纯黑背景与白色文字/平面图线条。Where home happens 标语始终单行。
- 六个案例横向排列，案例行默认位于页面下部，底部保留约 32px 空隙，以约 35px/s 向左无缝循环。没有章节筛选、缩放或拖动画布。
- 悬停案例时，整行在可用空间内轻缓下移，留出上方案例标题空间；移开后回到页面下部。自动限制下移距离以避免超出屏幕。
- 滚动时标语缓缓淡出；悬停平面图时，主标题切换为该案例名，示意图保持比例放大至页面下半部，其他卡片淡出且滚动暂停。放大和缩回共用约 1.1 秒可逆动画，快速移入移出从当前位置继续，不重新起跳。
- 悬停时直接在主页面阅读：左侧为来源记录、地点年代与原始来源链接，中间为平面图，右侧为项目解读、研究边界及前后案例切换。
- 在文字、平面图和来源链接之间移动鼠标不会关闭阅读状态。不再需要打开弹窗。移出阅读区域后，图像沿原路径缩回，标题交叉淡化恢复，随后继续滚动。
- 可通过 BACK TO SPACES 或 Escape 退出阅读状态。
- 键盘聚焦案例显示完整阅读布局，按 Enter 可聚焦来源正文；触屏点击案例后，平面图、来源和解读在同一可滚动区域上下排列。
- 系统减少动态效果时直接切换，不播放缩放动画。
- 阅读区的 PREVIOUS / NEXT 可循环浏览六个案例，文字与图像同步更新。原有详情弹窗及相关代码已移除。
- 已移除标语下方短线，以及案例行下方的说明、播放控制、标语与页脚。
- 手机保持横向排列，可原生左右滑动；系统开启减少动态效果时不自动滚动，标语保持可见。
- 页面不上传数据，不使用追踪脚本。循环副本从读屏导航隐藏，原始六个案例支持键盘访问。

## 编辑

修改 index.html 中的 h1 调整主标语。script.js 的 CASES 保留双语研究内容，格式为 [英文, 中文]，当前显示英文。evidence 为资料记录，meaning 为分析，limit 为研究边界；SOURCES 为来源索引。六张 SVG 是原创解释性示意图，不是测绘图。

styles.css 中的 :root 控制原有配色；.case-study 控制卡片宽度，.case-group 控制间距。script.js 的 animateCases() 中 scrollSpeed 的目标值 .035 控制滚动速度。`.headline-default` 与 `.headline-case` 控制标题淡入淡出；`.floorplan-preview` 控制放大区域，`showPlan()` 中的动画控制自然缩放时长。

## 修改后检查

确认六个案例按顺序循环、循环边界无空白；悬停暂停和移开恢复；标语随滚动淡出，悬停平面图切换案例名且图像等比放大；移开后恢复；左右正文和来源链接可读取；在文字和图像之间移动不关闭阅读；键盘可访问最后一个案例；手机无整页横向溢出；减少动态效果时不自动播放。

## Integrated photograph section

照片已整合为每个案例下方的第二屏，不再使用弹窗或独立图库。阅读案例时，向下滚动可平滑切换到该案例的两张照片；在照片屏向上滚动可返回相同案例的平面图与正文。PHOTOGRAPHS ↓ 和 BACK TO THE STUDY 提供键盘与触屏备用入口。

正文栏有溢出时，滚轮先滚动正文；到达底部后才能进入照片屏。切换过程中保留当前案例、文本滚动位置和已暂停的水平图谱。触屏点击后的阅读状态保持打开，避免移动内容时误触退出。手机照片上下排列，可以滚动阅读完整图注。

照片屏只显示简洁的案例标题、两幅完整照片、图注与摄影者/许可署名，已移除额外原始来源与许可导航链接。完整来源链接仍保存在照片元数据和 assets/photos/CREDITS.md 中。没有筛选器、缩略图或上传控制。

assets/photos/ 中包含 12 张本地参考照片，每个案例两张。摄影者、出处和许可另存于 CREDITS.md 与 credits.json。所有图像都是参考来源的真实照片，为网页等比缩小，未裁剪。

图注区分住宅参考、历史照片与博物馆重构。前厅照片未确认是研究中的特定 McMillan 装置；纽约 Tenement Museum 照片未确认是 Levine 家庭公寓，不应将其误标为相应具体历史家庭。

PHOTOGRAPHS 数组保存 id、caseId、src、alt、caption、credit、sourceUrl、license 和 licenseUrl。新增或替换照片时保留准确描述与来源。照片随项目保存，无需外部网络即可显示。

修改后检查：滚轮下移进入当前案例照片、上移返回同一案例；长正文可先滚动阅读；两个屏幕间没有弹窗；键盘按钮和 Escape 可返回；触屏内容保持打开；手机两张照片及全部图注可访问。

## Layout toggle

首页右上角 GRID VIEW 切换到静态网格：桌面每行三例、两行共六例，停止循环滚动并移除循环副本。SCROLL VIEW 可返回水平滚动模式。网格中的案例仍支持悬停、键盘阅读和下滚进入照片。平板采用两列，手机采用单列以保持图像和文字可读。

## Monochrome palette

styles.css 的 --background / --surface 均为 #000000，--foreground 为 #ffffff。SVG 的墙体、家具线条、图注和尺寸标记均改为白色；家具底色为黑色。

照片屏同样使用黑色背景和白色文字，照片通过 CSS grayscale(1) 以黑白显示。原始照片文件没有修改，来源与许可记录保留；图注注明黑白显示。网格、滚动、悬停阅读和上下滚动照片屏功能保持一致。
